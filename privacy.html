Privacy Policy

Around The Frame Poster · Last updated September 16, 2026

1. What this tool is

Around The Frame Poster is a personal automation utility operated by its owner to publish the owner's own photo carousels to the owner's own TikTok account via TikTok's official Content Posting API. It has no other users.

2. Data collected

The Tool stores only what TikTok's OAuth flow returns and what is needed to post:

  • TikTok access and refresh tokens for the operator's own account;
  • the operator's TikTok open ID / account identifier;
  • the photos and captions the operator chooses to publish.

No data is collected from anyone else, because there are no other users.

3. How data is used and stored

Tokens and account identifiers are stored on the operator's own private server and used solely to authenticate with TikTok's API and publish the operator's content. They are never sold, shared, or used for advertising.

4. Data sharing

Data is transmitted only to TikTok's official API endpoints as required to authorize and publish posts. No other third party receives any data.

5. Retention and deletion

Tokens are kept only while the Tool is in use. The operator can revoke the Tool's access at any time from TikTok's authorized-apps settings, which immediately invalidates the stored tokens, and can delete the stored data from the server at any time.

6. Security

Stored credentials are kept in files readable only by the operator's server process and are never published or committed to public repositories.

7. Changes

This policy may be updated at any time; the version published at this URL is the current one.

8. Contact

Questions about this policy: contact the operator through the TikTok account @around_the_frame.
